# ios16mcdonaldfix
Getting Mcdonald App working after the drop of the support in iOS 16.

This version of McDonald is based on the version 3.39.1, which is the last compatitable version of McDonald in iOS 16. By modifying the value and matching the lastest version of McDonald, it will completely restored the function of McDonald app.

Currently ,almost all of the features of McDonald app works in this patched version of McDonald. For example viewing the menu , locating the nearest restaurant, login in to the McDonald system, Ordering food and Complete the Payment, Using the featured Coupon , Playing Mini Games.

# Installation :

For iOS 16.0 - 16.6.1, 16.7 RC

Using trollstore to install it.
For futher steps on installation of trollstore, you may refer this link : https://ios.cfw.guide/installing-trollstore/

For iOS 16.7 - iOS 16.7.16

Using Sideloadly to sideload the ipa with computer. You will have to refresh the app every 7 days
